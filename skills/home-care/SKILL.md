# Home care reference

A short, general reference for everyday family health. Read the file you need:
- [red-flags.md](red-flags.md): anything here is an emergency. Check it on every assessment.
- [conditions.md](conditions.md): common complaints — what to ask, home care, when to see a doctor.
- [risk.md](risk.md): who needs a lower threshold (age, conditions, pregnancy).
- [medicines.md](medicines.md): everyday medicine rules and dosing by weight.

Base decisions on these facts, not on how uncertain you feel. When this doesn't cover something, look it up.
