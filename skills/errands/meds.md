# Medicines

## Zepto — https://www.zepto.com
- Quick delivery (minutes) for over-the-counter items: paracetamol, ORS, thermometers, plasters. Not for prescription-only medicines.
- Asks to "Select Location" before showing any products: set the address first. Login is phone number + OTP.

## Picking the product
- Match the form to the person: children get syrup or suspension (check the strength, e.g. paracetamol 120 mg/5 ml or 250 mg/5 ml), adults tablets.
- Smallest pack that covers the need; check the expiry if it's shown.
